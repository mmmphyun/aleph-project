# tcpdump L4 캡처 스크립트와 로컬 모의 검증

이번 완료 범위는 **캡처 스크립트 및 로컬 모의 검증**이다. 실제 캡처는 수행하지 않았다.
가짜 실행 파일의 `MOCK ONLY - NOT PCAP` 결과물은 pcap이나 실측 증거가 아니다.

## 사용법과 실행 환경

```bash
bash network/tcpdump_capture.sh 192.0.2.10 22 eth0 './captures/test capture.pcap' 10 1000
```

위 명령은 향후 승인된 본인 테스트 트래픽을 캡처할 때의 예시이며 이번에는 실행하지 않았다.
실측 환경은 Linux Bash 4 이상, tcpdump, 소수 초를 지원하는 sleep이 필요하다.
출력 부모 디렉토리는 미리 생성하고 본인만 변경할 수 있는 신뢰 경로를 사용한다.
Git Bash는 이번 모의 테스트 환경이며 Windows 네이티브 캡처 지원을 의미하지 않는다.
경로는 POSIX 표기(`/c/...` 또는 상대 경로)를 사용한다. 스크립트는 `bash`로 실행한다.
tcpdump 자체의 캡처 권한이 필요하며 자동 sudo, 권한 또는 네트워크 설정 변경은 하지 않는다.

| 인자 | 기본값 | 제약 |
| --- | --- | --- |
| IPv4 | 필수 | 점으로 구분한 4개 옥텟, 각각 0~255, 선행 0 금지, DNS/IPv6 제외 |
| TCP 포트 | 필수 | 1~65535, 선행 0 없는 십진 정수 |
| 인터페이스 | 필수 | 영숫자로 시작하는 1~15자, 이후 영숫자·`_ . : -`, 전체 인터페이스 `any` 금지 |
| 출력 경로 | 필수 | `.pcap` 확장자, 제어문자 금지, 부모 디렉토리 쓰기·탐색 가능, 기존 파일/디렉토리/심볼릭 링크 금지 |
| 캡처 시간 | 10초 | 1~120초, 선행 0 없는 정수 |
| 패킷 수 | 1000 | 1~100000, 선행 0 없는 정수 |

필터는 `ip and tcp and host <IPv4> and port <포트>`이며 양방향 중 해당 주소·포트에
일치하는 패킷만 허용한다. SYN만 제한하지 않아 ACK/RST 및 핸드셰이크 분석에 사용할 수 있다.
`-nn -p`로 이름 해석 및 promiscuous 모드를 끈다. `-U`로 패킷 단위 기록을 요청한다.
모든 값은 인자 배열로 전달하며 `eval`을 사용하지 않는다.
`noclobber`로 파일을 독점 생성하고 `-w -`의 표준 출력을 열린 FD에 연결해 경로 재오픈을 피한다.
생성 권한은 umask 077이다. 실패해도 빈 파일 또는 부분 파일을 남기며 자동 삭제·재사용하지 않는다.

## 종료 및 실패 계약

| 코드 | 의미 |
| --- | --- |
| 0 | tcpdump 정상 종료(일반적으로 패킷 수 도달), 실측/pcap 유효성 보증은 아님 |
| 2 | 입력·출력 경로 검증 또는 파일 독점 생성 실패 |
| 124 | 시간 제한 도달 |
| 125 | 감시용 sleep 실행 실패 |
| 126 / 127 | 실행 권한 부족 / 필수 명령 부재 또는 실행 로더 오류 |
| 130 / 143 | 스크립트가 SIGINT / SIGTERM 수신 |
| 그 외 | tcpdump 비정상 종료 코드를 그대로 전달 |

tcpdump가 자체적으로 2/124/125/126/127/130/143 등을 반환할 수도 있으므로 코드만으로
원인을 구분하지 않는다. stderr의 `tcpdump 실행 실패`, `시간 제한 도달`, `사용자 중단`을 함께 확인한다.
캡처 권한 및 인터페이스 존재 여부는 tcpdump stderr와 종료 코드로 보고하며 사전에 root를 강제하지 않는다.

Bash SECONDS 기반 시간 감시와 0.1초 폴링을 사용한다. 정수 초 해상도 및 스케줄링 오차가 있어
정밀 타이머가 아니며, 시간 경계에서 이미 종료를 관측한 자식의 종료 코드를 우선한다.
SIGINT/SIGTERM과 시간 초과 시 저장한 자식 PID에 SIGTERM을 보내 버퍼 flush를 요청한다.
약 2초 유예 후에도 종료하지 않으면 SIGKILL하고 wait로 회수한다. 강제 종료 시 마지막 버퍼는
유실될 수 있다. 총 소요 시간은 설정 시간에 폴링·프로세스 시작·정리 시간이 추가될 수 있다.
다른 tcpdump에 대한 killall/pkill 또는 프로세스 그룹 종료는 사용하지 않는다.
감시용 sleep도 한 번에 최대 0.1초만 실행한다. SIGKILL·호스트 종료처럼 trap을 실행할 수 없는
상황은 정상 정리 계약에서 제외된다. 스크립트는 source하지 말고 별도 Bash 프로세스로 실행한다.

## 로컬 모의 테스트

`tests/unit/test_network.py`의 기존 SSH 테스트를 유지하고 캡처 테스트를 추가했다.
격리 PATH에는 가짜 tcpdump와 명시적인 sleep 래퍼만 둔다. fake가 없으면 실패하며 실제 tcpdump로
폴백하지 않는다. 가짜 출력에는 모의 결과 표기를 넣는다. 실 네트워크 연결은 사용하지 않는다.
정확한 인자·필터, 입력 오류, 공백/특수문자 경로, 기존 파일 보호, 명령 부재, 실패 코드,
시간 초과, SIGINT/SIGTERM, SIGTERM 무응답 강제 정리 및 무관한 프로세스 생존을 검증한다.
각 실행은 12초 상한, 가짜 장기 실행은 6초 자체 종료 상한을 두고 자식 PID 소멸을 확인한다.

검증 환경: Windows Git Bash 5.3.15, 실제 tcpdump 미설치.
2026-09-10 `powershell .\scripts\check.ps1` 실행 결과:

| 단계 | 결과 |
| --- | --- |
| 테스트 경로 검사 | 통과, 비표준 경로 발견 없음 |
| Ruff lint | All checks passed |
| Ruff format | 60 files already formatted |
| 전체 pytest | 136 passed, 4 skipped, 1 warning (14.01초) |
| 네트워크 테스트 | 91 passed: 기존 SSH 37개 유지 + 신규 캡처 54개, skip·경고 없음 |

기존 skip 4개는 collector, llm_analyzer, remediation, reporter 테스트에 각각 하나씩 있다.
기존 경고 1개는 `test_smoke.py::test_network_socket_is_blocked_by_default`의
pytest-socket DNS 차단 경고다. 이번 캡처 테스트의 실패·skip·경고와 혼동하지 않는다.
게이트의 마지막 성공 문구 외에도 네 단계 결과를 개별 확인했다.

## 미검증 및 후속 실측

- 실제 패킷 캡처, pcap 형식·내용의 유효성, 실 권한, 실제 인터페이스 동작은 미검증이다.
- 실제 tcpdump 버퍼 flush, Linux 신호 동작, 파일 권한 및 설치별 동작도 실측 확인이 필요하다.
- 본인 로컬 테스트 환경에서 주소·포트·인터페이스·출력 공간과 캡처 권한을 확인한다.
- 승인한 본인 트래픽으로 제한 캡처 후 실제 pcap을 열어 SYN/ACK/RST와 타임라인을 확인한다.
- 실측 환경·명령·종료 코드·캡처 시각을 기록한 뒤 보류 중인
  [Wireshark 보고서 이슈](https://github.com/mmmphyun/aleph-project/issues/28)에 연결한다.
  초안 브랜치와 `e7cbdeb`는 이번 변경에 포함하지 않는다. SSH/Hydra/Nmap 실행도 제외했다.
