# 회의록 (Meeting Notes)

## 개요
팀 정기/비정기 스크럼, 스프린트 계획, 회고 및 기술 의사결정 회의 내용을 기록하는 저장소입니다.
GitHub Actions를 통해 Notion 회의록 데이터베이스로 단방향 동기화될 수 있습니다.

## 작성 안내
- 포맷: 마크다운 (.md)
- 파일명 권장: YYYY-MM-DD-주제.md (예: 2026-09-04-sprint-kickoff.md)
- 필수 포함 권장 항목:
  - 일시 및 참석자
  - 주요 안건
  - 논의 내용 및 결정 사항
  - Action Items (담당자, 기한)
