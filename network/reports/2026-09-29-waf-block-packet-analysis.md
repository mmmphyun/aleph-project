## 목적·승인·구성

HTTP 차단 응답과 TCP 연결의 유지/종료/재설정을 서로 독립적으로 관측한다.
실제 승인자·시간대·계정/리전·VPC/EC2/Lambda/테이블·WebACL/IPSet ARN·룰 ID:
모두 미확정. URL/포트·정상 경로·출발지 IP·NAT/프록시·공유 IP: 미확정.
클라이언트 → 보호 엔드포인트 → 원본 경로와 캡처 위치/인터페이스/권한: 미확정.
배포 코드 해시·설정과 원격 지원 실행 명세: 대기. 실제 요청/PCAP 수: 0.

## 도구·시계·계획

| 항목 | 실측 기록 |
| --- | --- |
| curl/지속 HTTP 클라이언트/tcpdump/Wireshark 버전 | 미확인 |
| HTTP 버전·connection 정책 | HTTP/1.1 제안, 실제 미확인; HTTP/3 제외 |
| 각 장비 timezone·NTP 오프셋·timestamp 정밀도 | 미확인 |
| 캡처 start/end·snaplen·packet/drop count·bytes | 미확인 |
| 승인 요청/실행/시간/용량 상한 | 계획 제안만 있음; 실측 승인 없음 |
| 복구 담당·절차·완료 시각 | 미확정 |

단계는 기준선 → 제한된 기존 룰 요청 → 탐지/대응/IPSet 증거 → 동일 정상 경로 차단 응답
→ 유지 연결/새 연결 비교 → 승인 복구 후 회복 확인이다. 각 phase의 계획/실행 수·실패 원인은
실행 후 채운다. 응답 지연·수집 필터가 실제 탐지 조건에 미친 영향도 기록한다.

## 연결별 3-Way Handshake·종료 타임라인

캡처별 stream ID와 양끝 4-tuple을 기록한다. 다음은 빈 기록 틀이고 관측 결과가 아니다.

| 캡처 위치/파일·stream·4-tuple | UTC epoch·오차 | 송신 → 수신 | 플래그·seq/ack | 단계·해석 |
| --- | --- | --- | --- | --- |
| 미측정 | 미측정 | 클라이언트 → 보호 엔드포인트 | SYN 후보 미관측 | 기존/신규 연결 생성 미확인 |
| 미측정 | 미측정 | 보호 엔드포인트 → 클라이언트 | SYN/ACK 후보 미관측 | seq/ack 대조 필요 |
| 미측정 | 미측정 | 클라이언트 → 보호 엔드포인트 | ACK 후보 미관측 | 3-Way 완성 미확인 |
| 미측정 | 미측정 | 송신 주체 미확인 | FIN/RST/ACK 미관측 | 실측이 없어 종료 판정 불가 |
| 원본 측 별도 캡처 대기 | 미측정 | 프록시/로드밸런서 ↔ 원본 | 미관측 | 클라이언트 측과 다른 TCP 연결 |

실측 후 결과는 연결 유지(후속 응답으로 확인)/FIN 정상 종료 절차/RST 관측/관측 구간 내 종료
없음/캡처 부족으로 미확인으로 적는다. FIN 한 개를 완전 종료로 표현하지 않는다.
클라이언트 요청 완료 후 close·idle timeout·복구 시점 종료를 WAF 강제 종료로 단정하지 않는다.

## HTTP 상태·차단 원인·시간 대조

| 요청/phase·connection tuple | 송신/수신·HTTP 버전/상태 | Nginx event/CW ID·시각 | WAF requestId/action/rule/clientIp | 판정 |
| --- | --- | --- | --- | --- |
| 차단 전 정상 경로 | 미측정 | 미확인 | 미확인 | 기준선 없음 |
| 제한 요청 | 미실행 | 미확인 | 미확인 | 탐지 조건 충족 미확인 |
| 차단 후 정상 경로 | 미측정 | 미확인 | 미확인 | 403도 관측하지 않음 |
| 기존 연결 A/새 연결 C | 미측정 | 미확인 | 미확인 | 연결 재사용 미확인 |
| 복구 후 정상 경로 | 미측정 | 미확인 | 미확인 | 회복 미확인 |

| 시점 | 증거·식별자·UTC·정밀도·오차 |
| --- | --- |
| 요청 송신/응답 수신 | 미측정 |
| 서버 로그 이벤트 | 미확인 |
| 탐지/대응 시작·Lambda RequestId·incident_id·rule | 미확인 |
| IPSet API 완료·AWS 요청 ID·/32 주소 변경 | 미확인 (불리언 결과를 완료 시각으로 대입 금지) |
| 마지막 미차단/첫 원인 확정 차단 탐침 | 미측정; 전환 구간 및 누락/탐침 간격 오차 산정 대기 |
| FIN/RST 또는 연결 유지 확인 | 미측정 |

TLS PCAP의 HTTP 상태는 읽지 않는다. 제한된 클라이언트 관측과 서버/WAF 증거를 연결한다.
403만 있고 WAF 근거가 부족하면 “403 관측, WAF 원인 미확정”으로 기록한다.
custom response·CloudFront 변환이 있으면 실제 설정과 상태를 기록한다.
IPSet API 성공과 효력 전파를 구분하고 각 관측 위치의 전환 구간만 보고한다.

## 증거·복구·한계

| 종류 | 파일 식별자·SHA-256·비공개 보관 위치·보존기한 | 상태 |
| --- | --- | --- |
| 원본 PCAP/제한 필드 CSV/분석 JSON | 미생성 | 실측 대기 |
| 클라이언트 관측/WAF/Nginx/CloudWatch/대응 기록 | 미생성 | 대기 |
| 승인/배포/복구 확인 기록 | 미확인 | 대기 |

원본 PCAP은 커밋하지 않는다. 부분 결과도 보존하고 기존 파일을 덮어쓰지 않는다.
시계 차이·초 단위 로그·탐침 간격·전파 지연·capture drops·NAT/프록시·클라이언트 close 등
실제 측정 한계는 실행 후 작성한다. 복구는 담당자가 원래 주소를 보존하며 테스트 /32만
제거하고 정상 응답을 확인한다. 타 담당 리소스/코드 변경은 이 보고서로 대체하지 않는다.

**현재 결론: 준비 산출물만 작성. 운영 차단 성공·FIN/RST 원인·복구·10초 E2E 성공 미검증.**
